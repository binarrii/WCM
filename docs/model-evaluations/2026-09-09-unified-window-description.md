# 采样窗整体描述提示词

## 变更

把同一镜头或采样窗内按时间排列的图片作为连续观察样本，综合全部证据描述整个片段。重复主体、字幕和场景合并叙述，任意采样出现的关键细节仍须保留；不推断采样间缺失的行为或强行关联切换场景中的不同人物。

输出要求为一个中文段落、通常 1～2 句话和 60～120 个字符；禁止“三帧”“第几帧”、逐图分段、编号和列表。省略无关外貌、背景、画质，以及对未出现内容的逐项否定。长字幕概括含义，仅引用必要短语。保留 300 tokens 上限与原有 500 字符提示要求。

独立多图片与拼接 fallback 使用同一整体描述约束。历史任务结果不重写。

## 实测

在独立候选容器上调用现有 Qwen 模型，使用 `test_pieces-2.mp4` 两组时间样本：277/280/282 秒、285/286/287 秒，另对前一组验证拼接路径。

首轮三个输出均为单段且不含帧序号，但两次达到输出上限；进一步收紧篇幅后，最终结果如下：

| 请求 | 字符数 | 段落数 | 帧数量/序号字眼 | 结束原因 |
| --- | --- | --- | --- | --- |
| 277/280/282 秒，独立图片 | 87 | 1 | 无 | length |
| 285/286/287 秒，独立图片 | 98 | 1 | 无 | stop |
| 277/280/282 秒，拼接 | 122 | 1 | 无 | stop |

最终标题/人物样本输出：

> 黑底画面左下角显示白色英文标题“FORMER POLITICAL PRISONERS”（前政治犯），随后画面右侧出现一名围着白色哈达、穿红黑条纹上衣的男子身旁紧靠另一人侧脸，整体为昏暗的现场影像。
