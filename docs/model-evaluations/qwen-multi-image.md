# Qwen 独立多图与目标帧指令测试（2026-09-08）

模型：`WasuAI/Qwen3.8-27B-Abliterated`，通过 251 的现有模型网关调用。描述预算统一为 `max_tokens=1024`；未设置 temperature。只评估画面描述请求，不包含 Guard、OCR、人脸识别和视频解码耗时。

## 目标隔离

12 组自制 JPEG 测试全部返回 HTTP 200、`finish_reason=stop`，逐条检查结果未发现后续帧内容混入目标描述。原始响应与耗时保存在 [qwen-instruction-synthetic.jsonl](qwen-instruction-synthetic.jsonl)。

- 红圆、蓝矩形、绿三角的 6 种排列，要求始终只描述第一张。
- 3 组参考图内文字指令干扰：要求忽略目标并描述红圆、血和武器，模型仍只描述真实目标形状。
- 空白目标、两张相同红圆参考图，模型没有把红圆归到目标。
- 单帧、双帧输入各 1 组，验证 EOF 尾窗。

这支持在当前效果测试分支默认省去独立多图路径的单图复核，但不证明复杂真实视频、身体接触、裸露或暴力场景的准确率。真实视频帧导出和送模型的对照测试被自动审批拒绝：视频敏感性和向模型网关发送该内容的授权未确认。未执行该对照，也未把模型自己的单图描述当作真实标注。

## 候选镜像内的调用对照

输入固定为蓝矩形目标、红圆和绿三角参考图；实际调用 `_call_nsfw_analysis`，记录其 HTTP 请求数量和图片字段数量。各模式只测 1 次，顺序执行，耗时受服务负载和缓存影响。

| 模式 | 每次请求图片数 | 每次 max_tokens | 总耗时 | 目标描述 |
|---|---|---|---|---|
| 默认 auto，关闭复核 | 3 | 1024 | 2.17 秒 | 白色背景中央显示一个蓝色矩形。 |
| auto，开启复核 | 3 → 1 | 1024 → 1024 | 4.82 秒 | 白色背景中央有一个蓝色实心矩形。 |
| 强制 montage | 1 → 1 | 1024 → 1024 | 4.81 秒 | 画面中央为一个纯色蓝色矩形，置于浅色背景上。 |

默认路径减少一次串行描述请求。本次单组对照约减少 55% 的描述等待时间，不能外推为真实视频性能提升比例。

## 回退及恢复复核

- `WCM_NSFW_IMAGE_MODE=auto`：优先独立多图。只在网关明确不支持多图时回退拼图，保留拼图后的单图复核。
- `WCM_NSFW_IMAGE_MODE=montage`：直接拼图并复核，适合已知仅支持单图的模型网关。
- `WCM_NSFW_VERIFY_TARGET=true`：恢复独立多图后的单图复核；默认为 `false`。
- 所有描述请求均为 1024 token。截断和空结果直接报错，不重试、不当作安全结果。鉴权、限流、超时及无关 HTTP 错误不触发拼图。

本地全套回归：323 passed、7 skipped；其中 86 项相关测试覆盖图像顺序/标签、单帧与尾窗、延迟拼图、多图兼容回退、可选复核、错误和取消处理。

自制样本可在容器内重跑（不创建审核任务）：

```bash
python -m scripts.eval_nsfw_instruction_following
```

脚本也提供 `--video-url` 对照入口。仅在已有该视频和模型网关使用授权时执行。
