# WCM 登录 / 注册页视觉备选

四套 SVG 均已接入登录 / 注册页面：默认每次打开随机选择；手动选定后保存到当前浏览器，直到选择“每次随机”。下方文案候选及 HTML / PNG 保留为初版选型记录。

最终采用文案：**人物识别、违规审核，一站完成。** 辅助说明：**管理人物库，识别视频人物，检测违规内容，快速定位风险片段。**

依据项目实际用途：人物库管理、人脸检索、视频分析、时间线定位、审核任务追踪与结果导出。

## 背景

| 方案 | 原始 SVG | 视觉方向 |
| --- | --- | --- |
| A 深蓝光学（推荐） | `a-optical-depth.svg` | 深蓝光学层、视频帧、识别框；适合突出专业审核产品 |
| B 银白玻璃 | `b-silver-frames.svg` | 银白空间、蓝色玻璃帧；最接近现有浅色界面 |
| C 青绿扫描 | `c-signal-scan.svg` | 参数化点云人脸、扫描平面与信号线；突出人脸识别 |
| D 靛紫流光 | `d-spectral-flow.svg` | 光谱曲面与细密流线；更抽象、偏品牌展示 |

四张背景均为原创纯 SVG，1920 × 1080，适用于 CSS background-size: cover；不包含产品文案、表单、位图、人脸照片、外部字体或脚本。参数化人脸是虚构几何图形。提供 SVG `<title>` 与 `<desc>`，用于装饰背景时建议 `aria-hidden="true"`。正式接入时应根据屏幕比例调整位置，保证文案区域留白。

`preview-a.html` 至 `preview-d.html` 为自包含设计预览，不会调用登录接口。PNG 为浏览器实际渲染截图；`contact-sheet.html` 为四图对比入口。

## 文案候选

共同眉题：**智能内容审核工作台**。

| 编号 | 主标题（斜杠为换行） | 辅助说明 |
| --- | --- | --- |
| 1 功能直述（推荐） | 人物识别， / 视频审核，一站完成。 | 管理人物库，识别视频人物，快速定位审核结果。 |
| 2 审核流程 | 从人物检索， / 到视频审核。 | 人物库管理、视频分析、任务追踪，汇集于一个工作台。 |
| 3 结果定位 | 定位关键人物， / 追溯视频线索。 | 人脸检索与视频分析，让审核线索清晰可查。 |
| 4 效率导向 | 让内容审核， / 更高效。 | 统一管理人物、视频与审核任务，集中查看识别结果。 |
| 5 简洁操作 | 人物与视频， / 一站式审核。 | 建人物库、查人脸、审视频，快速查看与导出审核结果。 |

表单建议：登录标题“欢迎回来”，说明“登录，开始人物识别与视频审核。”；注册标题“创建 WCM 账户”，说明“注册，进入智能内容审核工作台。”。

## 再生成

1. `python3 generate_backgrounds.py`：生成 SVG。
2. `python3 build_previews.py`：将 SVG 嵌入预览，保留各图独立 SVG ID。

正式页面位于 `webui/src/views/AuthPage.vue`，背景样式独立放在 `auth-background.css`，避免影响账户安全等共用表单页面。正式 SVG 位于 `webui/src/assets/auth-backgrounds/`；偏好逻辑位于 `webui/src/services/authBackgrounds.js`。部署与验证记录见 `deployment.md`。
