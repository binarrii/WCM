# 小对象圆环十字标验收

## 显示约定

- 宽、高都不超过 32 个视频原始像素的旗帜、徽标、裸露部位，显示绿色圆环十字标。
- 以扩张前 bbox × HTMLVideoElement.videoWidth/videoHeight 判断，采用原始视频像素，不使用播放器 CSS 尺寸。
- 圆环十字标居中于原始 bbox，点击区域固定为 32×32 CSS 像素；到画面边缘时截断，不移动中心。
- 其余对象保留 1.25 倍扩框，人脸保持原有尺寸与显示行为，坐标转换和持久化结果不变。
- 点击圆环十字标打开信息浮层并选中关联记录，再点同一个标记关闭。点另一小标记切换浮层。
- 支持 Enter/Space 操作，Escape 收起。播放/切换采样帧、过滤掉对象、隐藏标记时清理浮层。
- 缩放播放器/进入全屏不改变对象类型；视频尺寸不可用时不猜测小对象类型。

## 本地验证

前端 128 项测试通过，生产构建通过。新增回归覆盖 32px 包含边界、32.001px 排除、
长而窄的对象保持框、扩张前判断、播放器缩放、缺失视频尺寸、人脸不变、四边中心与截断。

使用实际 FaceOverlay.vue 与对象数据处理模块，在临时 Vite 页面进行浏览器交互验收：

| 场景 | 结果 |
|---|---|
| 原视频 1920×1080；16×16、32×32 对象 | 绿色圆环十字标 |
| 33×33、120×90 对象 | 保留原框 |
| 16×16 人脸 | 保留人脸原框 |
| 首次点击、再次点击 | aria-expanded true → false，浮层实际显示 → 隐藏 |
| 点另一小对象 | 切换到该对象的信息浮层 |
| 完整框模式 | 小对象仍为十字标，浮层不被旧 hover/selected 样式强制打开 |
| Escape、Enter | 收起、重新打开 |
| 播放器从 960×540 变为 1440×810 | 类型不变，十字标点击区域约 32×32 显示像素 |
| 切换采样帧 | 无当前帧时无标记，恢复后浮层默认关闭 |
| 隐藏模式 | 无 overlay |

浏览器未出现运行错误。未调用对象模型或重新提交视频审核。
