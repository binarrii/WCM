# 三帧滑动窗口

视频审核、独立 NSFW、OCR 文本检测和人脸检索共用 `api/utils.py` 的 `VideoFrameSampler`。

- 按时间采样：每帧解码后读取 `CAP_PROP_POS_MSEC` 提供的呈现位置，在 `0、interval、2×interval…` 固定时间网格上选择到达该时刻的第一帧。下一采样点由固定网格计算，不从上次实际帧时间累加，避免非整数 FPS 带来的累计偏移。结果保留所选帧的真实时间到毫秒，例如采样截止点 99 秒之后第一帧在 99.6 秒，就记为 `00:01:39.600`。
- 可变帧率使用解码时间；时间戳缺失、无效、重复或倒退时，仅对受影响帧按最近有效时间和 FPS 估算，记录警告及 `estimated_timestamps` 计数。无效 FPS 回退到 25。此降级情况下不能保证真实时间精度。零间隔表示逐帧采样；单帧跨越多个采样点时不复制帧。
- 窗口长度 3，步长 1。例如采样帧 `A B C D` 产生 `ABC`、`BCD`、`CD`、`D`；每个采样帧恰好一次位于窗口第一位。
- 到视频末尾按实际剩余帧数提交，不补帧、不复制尾帧。不增加偏离原采样间隔的额外帧。只有 1 或 2 个采样帧的视频也能处理；没有采样帧时不请求模型。
- NSFW 默认使用 `WasuAI/Qwen3.8-27B-Abliterated`。一次请求传入 1～3 个独立 `image_url`，每张前放置 `TARGET 1` / `CONTEXT 2/3` 与实际采样时间标签；图片按比例缩至长边最多 1024 像素、JPEG 质量 90，不拼接、不裁剪、不补帧。第一帧始终是结果对应的目标，后续帧仅辅助理解已经可见的动作，镜头切换后不能推断连续性。图片内文字不得作为指令执行。
- 默认 `WCM_NSFW_IMAGE_MODE=auto`、`WCM_NSFW_VERIFY_TARGET=false`。正常多图路径只请求一次描述，随后进入原有 Guard 判定；不额外请求单图复核。可设 `WCM_NSFW_VERIFY_TARGET=true` 恢复第二次目标单图复核；只有固定词表映射出的核查方向能传入复核，原始上下文描述不能直接传入。
- 网关明确返回不支持多图或最多一张图的错误（HTTP 400/422/500/501）时，自动回退到原拼图：目标为大图、参考帧为缩略图，标签置于图外。拼图路径始终保留第二次单图复核，仅复核描述进入 Guard。已知只支持单图的网关可配置 `WCM_NSFW_IMAGE_MODE=montage`，直接采用该路径，避免每个窗口先尝试多图。拼图按需生成，正常路径没有拼接开销。
- 所有 NSFW 描述请求统一 `max_tokens=1024`，不再因截断自动提高预算重试。超时、鉴权失败、限流、无关 HTTP 错误、空结果和截断结果直接使审核失败，不触发额外拼图请求，也不把不完整描述视为安全画面。图像模式回退最多一次；复核失败不能使用首轮描述替代。
- 窗口结果仍标注第一帧的实际时间，模型输出不能改变时间戳。人物区间按实际采样点的相邻关系合并，避免可变帧间距造成误拆分；采样点缺失结果或没有该人物时打断区间。
- 相邻窗口共享画面及 JPEG 编码，综合审核继续使用原有有界队列与并发消费者。解码失败或任务取消时释放视频句柄和消费者。

窗口功能不涉及前端或接口返回结构变更；图片输入仍作为单帧处理。

本测试分支根据自制画面的目标隔离与干扰指令测试，默认省去独立多图路径的单图复核。该测试不能证明复杂真实视频零串帧或零误判；保留开关便于对照测试和恢复。综合审核的有界队列与并发上限、Guard 请求、OCR 和人脸检索均不变。测试记录见 `docs/model-evaluations/qwen-multi-image.md`。
