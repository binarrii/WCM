# 视频采样与场景窗口

综合审核和独立 NSFW 默认使用“准确优先”的场景采样：检测镜头边界、限制参考图范围，只减少高度相似的视觉审核请求。OCR 和人脸始终使用原来的固定时间采样网格。

## 时间与覆盖

- 每帧解码后读取 `CAP_PROP_POS_MSEC`，在 `0、interval、2×interval…` 的绝对网格上选取到达该时刻的第一帧，不从上次实际帧时间累加，避免非整数 FPS 漂移。
- 结果保留所选帧的真实时间到毫秒。可变帧率、较大 PTS 间隔不会复制帧；无效或倒退的 PTS 从最近有效时间和 FPS 估算，并记录警告。零间隔表示逐帧采样。
- 每个原网格采样点继续做人脸和 OCR。视觉专用的镜头边界补采帧不额外做人脸/OCR，也不打断原来的人物时间区间。

## 场景采样

- 本机逐解码帧计算小尺寸画面的颜色、亮度变化，不额外调用模型。超过切镜阈值后先排空旧镜头窗口，再开始新窗口，避免参考图跨越已检测到的镜头边界。
- 每个镜头保留原网格上的首尾采样目标；已有网格采样覆盖的镜头不额外请求边界帧。完全位于两个固定采样点之间的短镜头补采一张首帧，避免整段镜头没有视觉目标。视频末尾不复制、不补造帧。
- 每个窗口仍最多三张独立图片，第一张是目标，其余仅作同镜头参考。短镜头和镜头末尾可以只有一张或两张图片。
- 动态步长只作用于视觉目标。当前候选与上一次选中的目标在全图及局部网格都高度相似时，跳过该候选的 Qwen 描述和后续视觉 Guard 请求；画面变化则恢复审核。比较上一审核目标可以避免缓慢变化逐步累积后仍被跳过。
- 稳定场景也定期复查，默认不超过三个基准采样周期；镜头首尾的采样目标总是审核。实际时间间隔还受解码帧的 PTS 间隔限制。
- 跳过的目标不生成伪造描述或“模型已审核”的结果。实际发出的请求仍使用现有帧级错误隔离；失败保留未完成项，后续窗口继续。
- 正常结束时日志记录 `fixed_samples`、`scene_cuts`、`boundary_samples`、`visual_targets`、`visual_skipped`，便于核对覆盖和请求节省量。`visual_targets` 是计划审核目标数；网关拼图回退或主动复核可能使实际模型调用数更多。

## 配置

Compose 支持以下环境变量，本地开发也可通过 `.env` 设置：

| 配置 | 默认值 | 作用 |
| --- | --- | --- |
| `WCM_NSFW_SAMPLING_MODE` | `scene` | `scene` 开启场景采样；`fixed` 恢复旧版三帧、步长一滑窗 |
| `WCM_NSFW_SCENE_MAX_STRIDE` | `3` | 稳定画面的最大视觉间隔倍数，范围 1～10 |
| `WCM_NSFW_SCENE_CUT_THRESHOLD` | `27` | 颜色/亮度变化阈值；更低会切分更多边界 |

旧版 `fixed` 模式下，`A B C D` 产生 `ABC`、`BCD`、`CD`、`D`，每个采样帧恰好一次作为目标，不增加网格外边界帧。两种模式共用 PTS、JPEG 缓存、有界队列和取消清理逻辑；单张图片输入不受采样模式影响。

## 模型请求

- 视觉模型为 `WasuAI/Qwen3.8-27B-Abliterated`，一至三张独立 `image_url` 带 `TARGET 1` / `CONTEXT 2/3` 和真实时间标签；按比例缩至长边最多 1024 像素，JPEG 质量 90，不裁剪或补帧。
- 默认 `WCM_NSFW_IMAGE_MODE=auto`、`WCM_NSFW_VERIFY_TARGET=false`。正常多图路径只请求一次描述，再由 Guard 判定。可开启单图复核；只有固定核查方向能传入复核，原始上下文描述不能直接传入。
- 网关明确不支持多图时才回退拼图，拼图路径保留目标单图复核。无关超时、鉴权或限流不会触发额外拼图请求。
- Qwen 和 OCR 输出上限 1024 tokens，Guard 为 512。截断输出保留已有内容，记录 WARNING 后继续解析，不因截断重试。空 OCR 跳过文字判定；有效 `Unsafe` 和 `Controversial` 都进入需审核结果。

## 验证范围

镜头检测是基于画面变化的启发式，不等同于语义场景理解；运动、闪光可能造成多切，渐变或外观接近的镜头可能漏切。相似度筛选不能保证短暂或极小内容零漏检。

准确优先会补采原网格没有覆盖的短镜头，所以重复片段可以减少视觉请求，频繁切镜片段也可能增加请求。不能仅凭窗口算法承诺整条视频加速或准确率提升；需要结合具体视频统计和模型结果评估。

回归覆盖固定模式兼容、短镜头、单帧镜头、局部变化、渐变、真实 PTS、人脸/OCR 固定覆盖、边界不误拆人物区间、模块失败隔离和取消清理。采样统计不调用外部模型，也不把历史任务改判为安全。
